# Devnet Deployment Record

This file is generated by `scripts/setup-devnet.ts` — rerunning the script overwrites the table
below with the current on-chain addresses. Do not hand-edit the table; the script also parses it
back out on the next run to decide what already exists and skip recreating it.

**Status:** not yet deployed.

## How to deploy

```bash
anchor build && anchor deploy --provider.cluster devnet
yarn setup:devnet
```

`setup:devnet` is idempotent: it creates the stake mint ("TEST", 9 decimals) and reward mint
("RWD", 9 decimals) only if this file doesn't already record them, mints 1,000,000 TEST to the
wallet the first time the stake mint is created, and calls `initialize_pool` only if the pool
doesn't already exist on-chain. Once it succeeds, this section is replaced with a table of:

- Program ID
- Deploy tx
- Stake mint (TEST)
- Reward mint (RWD)
- Pool PDA
- Vault ATA
- Cluster
- Last updated date

To fund an additional address (e.g. an agent wallet) with TEST after the initial setup, without
re-running everything above:

```bash
yarn setup:devnet -- --mint-to <PUBKEY> <AMOUNT>
```
